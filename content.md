# README.TXT

WELCOME

This is a small personal web server.

Most pages can be read normally in a browser.

Some resources also have plain-text or structured versions.

Useful places:

```
/guestbook/
/wall/
/notes/
/files/
/archive/
```

Everything in these directories should be assumed public.

Stable links are intentional.

If you find something useful, you may link directly to it.
